## Original project artwork
Cabinet geometry, colliders, UI, icon, collectible medallions and synthesized audio are original procedural assets created for this project.

The lathed token with embossed star, beveled cabinet geometry, chrome hardware and glass detailing are original procedural models.


Premium circus printed atlas (premium-circus-atlas.png) was created with the built-in image_gen tool for this project; it is original generated artwork. The premium cabinet is actual procedural geometry; its shop preview is captured in-engine, not a concept render. The source concept and its generation prompt are recorded in docs/design/2026-09-29-premium-clown-proposal.md.
