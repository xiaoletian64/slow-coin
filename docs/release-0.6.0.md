# 0.6.0 测试版

- 每日称号 8 个、永久称号 24 个；收藏册内查看进度和佩戴，每日按设备当地日期刷新。
- 短双导杆和出币窗口联动；出币期间继续抽奖，奖励队列存档。
- 累计大量待出金币转成真实金币塔；超过 29,999 枚可主动选择轮盘结算，同时结算当前和排队抽奖机会，保留原钱包及台面金币。
- 前口实收数字、真实碰撞哗啦音效、保留钱包重开、图片定制金币。
