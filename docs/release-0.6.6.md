# 0.6.6 — 幸运彩球砸台

每次成功接受投币独立以 1% 概率触发彩球事件，派奖币不额外掷此概率。练习台同样可触发，但不增加正式收益。

动画包含落点光圈、旋转彩球下落、冲击光波与反弹消失。撞击向附近下盘金币施加随机方向和力度的物理冲量；上方钉板不受冲击，只有实际前口掉落才到账，侧落不计奖。

多个彩球依次播放，落点、进度及已冲击标记保存；恢复后不会再次施加已完成的冲击。

同时包含持续投币修正：不因台面币数停止投币或落币，超过 1,000 枚随机消除 50 枚，消除不计收益。

验证：彩球概率穷举、真实冲量、上盘隔离、存档与重复冲击防护，以及持续投币、旧存档、奖励结算、币塔、满盘、连抽上限和重开等 9 项测试通过。已检查实际渲染的落球与冲击画面。部分无界面退出资源清理提示沿用已知问题记录。
