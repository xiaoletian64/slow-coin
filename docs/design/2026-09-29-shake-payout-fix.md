# 0.5.1 上方清币、出币布局与落币音效

用户反馈：摇晃后上方金币仍未落完；希望减少钉子、拉开唯一出币口和第一排钉子的距离；抽奖会停止，掉币声音不足。下方推盘仍按原要求不受摇晃力影响。

复现：旧 11 钉布局投入 32 枚形成币堆，3 秒后上方剩 24 枚，原 6 秒小幅随机冲量清理后仍剩 20 枚（builds/shake-before.log）。仅改为摇晃时上方钉子退让，同一场景剩 0 枚（builds/shake-after.log）。随后按用户要求减为上排 4、下排 3 根，横距 1.3；派奖口整体升高 0.45，实际出生点到首排距离由 1.46 增为 1.91。新布局同一场景自然落币后剩 1 枚，摇晃后 0 枚。

清理时上方钉子后退、暂时不参与碰撞；金币保留自身碰撞及真实重力，落入推盘后恢复普通推币。清理结束钉子回位恢复碰撞。存档恢复同时恢复钉板状态。导杆币继续沿杆正常释放；下盘不加冲量、不删币、不直接发钱包奖励。

声音补齐：此前仅处理币币碰撞和前方出口落币，静态金属台面/钉子接触被过滤。现在新发生且冲量足够的台面/钉子碰撞也触发落币声，持续接触不重复触发；落币和碰撞音量提高，背景音乐降低。保留群落币合并、静止不响、无按钮和数字计数滴答。

抽奖：没有改为并行开奖。当前一笔奖币吐完后再消耗待抽队列。新增真实物理流程回归：32 枚上方币，触发 58 奖励，再摇晃；当前三秒开奖正常结束，58 枚通过唯一出币口派完，随后自动开始待抽项。用户所说的其他停转情形仍待进一步定位，不能把此回归覆盖范围当成所有停转原因均已排除。

验证：051-test-shake_pile、shake_jackpot、collision_audio、outlet_audio、controls、guides、restore、circus、jackpot、premium、tower_physics 均通过。验证包括清理中恢复存档、32 枚守恒、钉子复位、空台面落币声、静止不响、下盘不受冲量。部分独立 headless 测试退出时仍有原有音频资源释放警告。Android APK 签名验证通过；iOS 模拟器目标编译通过。
