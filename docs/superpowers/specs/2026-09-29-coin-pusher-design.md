# 慢慢推 · 双平台推金币首版设计

> 规则修订：本文件为历史方案。经济、老虎机与外观冲突项以 [小丑机修正规则](2026-09-29-circus-correction.md) 为准，不再使用直接钱包派奖或侧落回流。

用户已确认：Android + iPhone 原生手机游戏；竖屏；按一次投一枚，长按不连投；推板自动往复；真实 3D 金币碰撞；无内购；每日至少 5,000 金币；现成模型优先。2026-09-29 用户授权开始实现。

## 首版范围
一台经典双层机台、左右选择投币位置、单次投币、钱包、每日补给、独立练习台、永久收藏、暂停、声音与触感开关、本地存档。后续扩展其他机台。离线运行，无广告和联网权限，无账号和统计 SDK。

## 技术与边界
Godot 4.6.3 + GDScript，使用本机已安装的同版本 Android/iOS 导出模板。Jolt 3D 物理，Compatibility 渲染确保移动端覆盖。同一工程输出 Android APK 和 iOS Xcode 工程。iOS 模拟器使用无签名构建；真机/商店签名需用户 Apple Team，不能冒充已交付签名 IPA。

模块：Wallet（纯规则与验证）、SaveStore（原子存档与备份）、Coin（刚体及渲染）、Machine（台面与推板）、Game（状态编排）、HUD（触摸与界面）、Audio（反馈）。UI 按 450×900 逻辑尺寸适配安全区和不同长宽比。

## 经济与节奏
初始 10,000，当天首次进入另发 5,000；以后按本地自然日首次进入发 5,000。补给日严格递增，重复/回拨不重复发放；离线游戏不能防止用户手动把时间调向未来。每枚成本/返还 10。侧落累计 20 枚奖励 50 金币并推进收藏；规则界面公开。收藏每累计正式投币 50 次解锁一款永久纪念章，不影响收益。没有签到连续奖励、限时绝版和推送。

练习模式无限免费投币，独立台面，不计钱包和正式进度；切换时保存/恢复对应台面，防止练习金币转移套利。台面容量 240 枚；容量满/投币队列满时不扣钱。每次接受投币先记入待投队列并存档，出票后移入台面，以免恢复丢失已扣金币。

## 输入与生命周期
按钮按下信号，一次按下产生一次请求；不按住重复，不用持续按键状态轮询；键盘事件忽略 echo。投币队列串行出币，反馈即时。暂停、弹窗、切后台停止物理和出币；前台不自动继续，点击继续后恢复。自动存档保存钱包、补给日期、设置、队列、推板相位和两套台面中每枚金币的位置、姿态、线速度和角速度。关闭立即存档。

## 视觉
深海蓝背景、奶油白文字、黄铜边框、暖金金币、少量薄荷绿灯带。机台占据屏幕中心，钱包在顶部，底部实体感大按钮。中文优先；字体随包附带 OFL 字体，不依赖手机系统字体。下载 CC0 Kenney 金币/宝石作为正式模型或展示装饰，机柜和碰撞体用可调参数自建；记录第三方授权。

## 验收
自动化验证经济、日补给去重、时钟回拨、余额不足、练习隔离、存档备份恢复、一次按压、队列恢复、暂停、碰撞/掉落/无穿模、容量保护。运行真实场景压测，保存截图。Android 导出并尽可能安装模拟器；iOS 导出后尽可能编译模拟器。报告准确区分通过与未验证项目，不宣称真机性能已验证。

## 用户追加确认（同日）
投币位置选择改为自动左右摆动的出币杆，可点击「停在这里」固定当前角度，再点击恢复摆动。杆端位置随摆角真实变化，金币从杆端进入物理世界；落点结果来自真实碰撞，不通过随机奖励伪造。摆杆相位、固定状态及已扣款待出币的位置/速度一起保存。继续交付 Android/iPhone 同一原生工程。

## 最新用户追加要求
- BGM 与音效独立开关；原创循环音乐。
- 游戏金币兑换永久机台皮肤，1500/3500/6000，收益一致。
- 三个垂直滚轮依次停下，三个同图案中奖，档位按用户要求为 58 / 388 / 2999 / 29999。60%空奖、30%58、8%388、1.8%2999、0.2%29999（可调整但必须公开且不随余额改变）。奖金完整计入钱包一次，物理落币为奖励演出，不重复计奖；推动的普通币正常返还。大额奖励用有上限的分批实体币演出，避免三万个刚体压垮手机。
- 用户选择两类推送方式都要：逐枚、整排、扇形、瀑布落币；经典双层、交错双推板、扫杆联动机台。不同机台独立保存台面。
- 余额严格低于500时，主动点击语音按钮，说「国安是冠军」，系统语音识别最终结果匹配后加5000；不设用户未要求的日限次，余额>=500不可领取。Android 使用系统语音识别 Activity，iOS 使用 Speech + AVAudioEngine 原生桥接。默认不录音，离开停止，不保存录音。
