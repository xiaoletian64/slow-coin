# 0.6.4 — 待抽次数提示与两次连抽上限

- 修复开奖及中奖演出覆盖待抽次数的问题：普通界面、高级皮肤和机台内屏幕持续显示“待抽 N 次”，不含正在进行的一次。
- 每轮中奖最多追加两次连抽。开始的次数和已排队名额共同占用上限，连抽再次中奖不重置名额；达到上限会显示提示。
- 连抽仍采用 5% 中奖率及 58／388 两档奖池。存档恢复、轮盘结算沿用次数限制。
- 旧存档超额排队机会收敛到剩余连抽名额，已确定的开奖结果、待出奖金及钱包保留。

验证：连抽接受/拒绝、执行计数、重进限制、旧存档迁移、开奖/演出/派奖/空闲次数显示，以及连抽概率、奖励守恒、轮盘、物理出币等 11 项针对性测试通过。无界面退出资源清理提示仍沿用已知问题记录。
